# Аудиоплеер DTF

Открыть `index.html` через локальный сервер:

```sh
python3 server.py
```

Адрес: http://localhost:8000

Аудио, обложка и аватар взяты из предоставленного MHTML. Иконки и токены — из локального SKILL.md. Волна рассчитывается по реальному аудиофайлу; при воспроизведении реагирует на частоты через Web Audio. Поддерживаются перемотка, клавиатурное управление ползунками, скорость 0.75–2×, громкость, mute и скачивание. Анимации учитывают prefers-reduced-motion.

## Варианты

- `variant-1.html` — первый вариант с большой обложкой.
- `variant-2.html` и `index.html` — исходная статья с компактным серо-синим аудиоплеером.
- `player-2.html`, `compact.css`, `compact.js` — отдельно разметка, стили и поведение нового блока.
